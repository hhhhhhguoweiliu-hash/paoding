# Roadmap

## v0.1 — Core pipeline
- Local video ingest, provenance, fixed-interval evidence frames.
- Evidence/Hypothesis/Recipe schemas.
- Reverse scaffold, recipe assembly, validation, packaging.
- Mock reproduction path that never claims empirical success.

## v0.2 — Closed-loop reproduction
- First real image/video adapters.
- Comparison scoring and visual review bundle.
- Ablation runner.

## v0.3 — Audio-aware reverse engineering
- Beat/onset/section analysis.
- Audio-video synchronization evidence.

## v0.4 — Skill Registry
- Catalog, routing tests, progressive disclosure.

## v0.5 — Multi-artifact
- Image, music, presentation, webpage and interactive-product adapters.

## v1.0 — Artifact Distillation Engine
- Stable cross-artifact evidence graph, reproducible adapters, transfer tests and versioned skill registry.
