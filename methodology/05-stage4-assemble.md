# Stage 4 — Assemble Equivalent Recipe

## Goal
Build the smallest executable workflow that explains and can reproduce the signature effect.

## Layers
- assets;
- generation / transformation;
- animation / motion;
- audio;
- edit / post;
- quality gates;
- export.

## Rule
The core recipe uses capabilities. Concrete model/provider choices are optional `tool_adapter` mappings and must retain alternatives.

Prefer the minimal graph that preserves high-impact decisions. Do not add nodes merely because they are common in AI-video workflows.
