# Stage 5 — Compare & Reproduce

## Goal
Empirically test whether the recipe reproduces the target effect.

## Comparison dimensions
Use only relevant dimensions:
- composition;
- style;
- identity;
- motion;
- timing;
- audio-sync;
- text;
- signature-effect.

## Status
- `unverified`: no real generation was executed.
- `attempted`: real generation executed but comparison is incomplete or failed.
- `verified`: reproduction test met the declared acceptance criteria.

A mock adapter can test plumbing only and must remain `unverified`.
