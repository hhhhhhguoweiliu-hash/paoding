# Stage 2 — Parallel Reverse

## Goal
Generate competing production hypotheses from different perspectives without collapsing them into a single story too early.

## Recommended lenses
1. Visual composition / art direction.
2. Character and identity consistency.
3. Motion / camera / temporal generation.
4. Prompt semantics and reference-asset strategy.
5. Editing / transitions / post-production.
6. Audio / rhythm / synchronization.
7. Text / subtitle / typography.
8. Failure signatures / artifacts / likely constraints.

## Hypothesis requirements
Each material hypothesis records:
- claim;
- evidence IDs;
- `O/S/H/U` level (hypotheses should normally be S/H/U, not O);
- attribution confidence;
- reproduction confidence;
- reproduction impact;
- alternatives;
- falsification test.

Specific model names without direct metadata are candidates, never facts.
