# Stage 6 — Encode Production Skill

## Goal
Convert a validated recipe into a reusable Production Skill.

## Production Skill must contain
- trigger description;
- boundaries / non-goals;
- required inputs;
- capability recipe;
- adapter suggestions as replaceable mappings;
- quality gates;
- failure recovery;
- positive, negative and boundary routing tests;
- at least one transfer reproduction test.

Do not encode a one-off artifact description as a reusable skill.
